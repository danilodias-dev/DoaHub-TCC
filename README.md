# 🌿 DoaHub - Plataforma de Solidariedade Transparente

O **DoaHub** é uma solução premium para conectar doadores a causas sociais com total transparência e rastreabilidade. Este projeto foi desenvolvido com foco em UI/UX de alto nível, utilizando o design system **Editorial Empathy**.

## 🚀 Tecnologias Utilizadas

- **Core:** React 19 + Vite 8
- **Estilização:** TailwindCSS (Vanilla CSS approach)
- **Animações:** Framer Motion (Transições fluidas e micro-interações)
- **Ícones:** Lucide React
- **Roteamento:** React Router Dom v7

## 📂 Estrutura do Projeto

A arquitetura segue padrões de escalabilidade e organização:

- `src/components/`: Componentes reutilizáveis (Layout, UI, Cards).
- `src/pages/`: Páginas divididas por contexto (Público, Auth, Doador, ONG).
- `src/hooks/`: Lógica customizada e estado global.
- `src/index.css`: Definições globais do Design System (tokens de cor, fontes, bento grid).

## 🛠️ Como Executar

1. **Instalar dependências:**
   ```bash
   npm install
   ```

2. **Rodar o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

3. **Gerar build de produção:**
   ```bash
   npm run build
   ```

## 🎨 Design System: Editorial Empathy

O projeto foi construído sob quatro pilares principais:
1. **Confiança:** Uso de grids organizados e tipografia autoritativa.
2. **Empatia:** Paleta de cores terrosas e verdes suaves.
3. **Clareza:** Foco total na rastreabilidade da doação.
4. **Premium:** Micro-animações e ausência de bordas rígidas, priorizando elevação por cores.
